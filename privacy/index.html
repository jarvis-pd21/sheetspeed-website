SheetSpeed Privacy Policy

Product: SheetSpeed (Chrome Web Store version 0.4.0) · Updated: October 25, 2026

Official website: https://sheetspeed.agi-jarvis.com/ · Chrome Web Store: Store listing · Store ID ljlmgielacploapelnjhodicgbjipcaa.

Published privacy policy for the SheetSpeed Chrome extension on the Chrome Web Store (0.4.0). Pro tools are free during early access. Contact jarvis@agi-jarvis.com or Support.

Effective October 25, 2026. Operator: Philip Dressler, California, USA.

SheetSpeed is a Chrome extension that adds keyboard shortcuts, formula tracing and modeling tools to Google Sheets, Google Docs and Google Slides. SheetSpeed Core (free) works entirely inside the open document. SheetSpeed Pro (free for everyone during early access; paid plans later) adds tools that read and write your spreadsheet through the Google Sheets API, but only after you connect your Google account. We do not sell personal data, use it for advertising, or use it to train AI models.

Early access: while Pro is in early access, SheetSpeed collects no license, account or payment data and does not contact ExtensionPay or Stripe. The sections below that mention ExtensionPay, Stripe, licenses or trials apply only once billing opens, and we will give notice in the extension and on our website before then.

Data SheetSpeed accesses

  • Document context (Core and Pro). On Google Sheets and Slides document pages, SheetSpeed reads the visible formula text, document and tab identifiers, the selected range, and native menu/control state so it can run the command you choose.
  • Google Docs (Core and Pro). On Google Docs document pages, SheetSpeed reads only the native menu, toolbar and key-tip state it needs to run the Alt shortcut you press. Docs are processed locally on the page only: SheetSpeed makes no API calls for Docs, requests no Docs permission from your Google account, and does not read, store or send your document text.
  • Keyboard events. SheetSpeed checks key presses against your configured shortcuts. It does not log ordinary typing or cell contents. Local diagnostics may keep the latest modifier event and element/menu metadata on your device.
  • Spreadsheet data (Pro, after you connect). When you run a Pro tool (trace dependents, goal seek, what-if tables, freeze panes, auto-color, font and fill color cycles, number format cycles, format painter, clear filters, clear all, Paste Exact, or image export), SheetSpeed calls the Google Sheets API for the spreadsheet you are working in to read the cells, formulas and formatting that tool needs, and, for tools that change the sheet, to write the result you confirm.
  • Slides images (Pro, only when you use Refresh from Sheets). When you press Ctrl+Alt+Shift+R (or click “Refresh from Sheets”) on a Google Slides slide, SheetSpeed reads that slide to find images previously exported by SheetSpeed (identified by the source spreadsheet link stored in the image’s link and alt text), re-reads that source range through the Google Sheets API, renders a new PNG in your browser, and replaces the image in place. It only touches the slide and presentation you are editing. Refresh runs when you invoke it. It does not run by itself, and it does not refresh charts, Google Docs, images that no longer carry the SheetSpeed source, or other slides.
  • Account and license (Pro, once billing opens; not collected during early access). Your email address and plan status (trial start, paid or not) through ExtensionPay.

Google account connection (Pro)

  • SheetSpeed uses Chrome's identity permission to ask Google for an access token. Google shows you a consent screen first, and nothing is connected unless you approve. Scopes are requested in two steps:
    • When you connect for Pro tools: https://www.googleapis.com/auth/spreadsheets, to read and write the spreadsheet you run a Pro tool on. Google’s grant can cover spreadsheets the account can access. SheetSpeed’s commands target the open spreadsheet, or the source spreadsheet linked from an image being refreshed.
    • Only the first time you use Refresh from Sheets in Google Slides: additionally https://www.googleapis.com/auth/presentations, to read the current slide and replace SheetSpeed images on it, and https://www.googleapis.com/auth/drive.file, which lets SheetSpeed create and manage files it created (and files you open with it). SheetSpeed uses that scope for the temporary PNG described below. It does not request full Drive access, and it does not list the rest of your Drive.
  • The token is managed by Chrome. It is used only from your browser, only to call the Google APIs listed under Permissions, and only for the spreadsheet or presentation open in your tab (plus, for Slides refresh, the source spreadsheet of each SheetSpeed image on that slide). SheetSpeed has no server that receives your token or your spreadsheet data.
  • The app may show Google's “unverified app” notice while Google's verification is pending.
  • You can disconnect from SheetSpeed's panel or Settings at any time, and revoke access at myaccount.google.com/permissions.
  • SheetSpeed's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Refreshing Sheets images in Slides (Pro)

  • Google Slides can only replace an image from a web address, so for each image being refreshed SheetSpeed uploads the new PNG to your own Google Drive as a temporary file (“SheetSpeed refresh (temporary).png”) and gives it a temporary “anyone with the link can view” share with discovery turned off, so it cannot be found by search. Anyone who obtains that link while the share is active can view the image.
  • The link is used only by Google Slides to fetch the image. Immediately afterwards, whether the update succeeded or failed, SheetSpeed removes the link share and deletes the temporary file. If removal fails, SheetSpeed tells you so you can delete the file yourself. If the browser closes before cleanup finishes, or an upload succeeded but its confirmation was lost, the next refresh finds that leftover temporary file (by its name or a SheetSpeed tag; drive.file shows files SheetSpeed created) and deletes it.
  • The image contains only the cells of the original exported range. The refreshed image keeps its size and position, and its link and alt text record the source spreadsheet, tab and range so it can be refreshed again. Nothing else is stored, and nothing is sent to a SheetSpeed server.

Storage

  • Shortcut settings, enabled state and timeouts are stored in Chrome local storage on your device. If you turn on settings sync, they are also stored in Chrome sync storage under your Chrome profile.
  • When a Pro tool changes your sheet, SheetSpeed keeps a local undo record (the original values and formatting of the affected cells) on your device so you can reverse the change. Undo records are bounded in size and you can clear them in Settings.
  • Once billing opens, the cached license status (paid / trial / none) is stored locally. ExtensionPay keeps a login token in Chrome storage.

Transmission and processors

  • Google (Pro only): Sheets API requests go directly from your browser to sheets.googleapis.com. Slides refresh requests go directly to slides.googleapis.com and the Google Drive API at www.googleapis.com/drive/v3 and www.googleapis.com/upload/drive/v3.
  • ExtensionPay (privacy, once billing opens; not contacted during early access): license and login checks. Your email and plan status are sent, but never your spreadsheet data. The early-access build does not include the extensionpay.com content script and does not call ExtensionPay.
  • Stripe (privacy, once billing opens): payment processing, receipts and the subscription portal. Card numbers never reach SheetSpeed or ExtensionPay. Stripe is not used during early access.
  • Developer servers: none. AI providers: none. The Chrome Web Store version does not include an AI helper.
  • This website: GitHub Pages and Cloudflare host the site, and the pages load a typeface from Google Fonts. Those requests are separate from spreadsheet content in the extension. Support email goes to jarvis@agi-jarvis.com.

Permissions

  • storage: settings, undo records and, once billing opens, the license cache, as described above.
  • activeTab: interact with the Google document you are using when you invoke SheetSpeed.
  • identity: get a Google access token, with your consent, for the Pro tools.
  • Host permission https://sheets.googleapis.com/*: call the Google Sheets API for Pro tools.
  • Host permissions https://slides.googleapis.com/*, https://www.googleapis.com/drive/v3/* and https://www.googleapis.com/upload/drive/v3/*: Slides refresh only (read the slide, replace the image, and upload, share, unshare, find and delete the temporary image file).
  • Content scripts on Google Sheets, Docs and Slides document pages (shortcuts, Alt key tips and panel; on Docs, local only with no API calls). The early-access build does not include the extensionpay.com content script at all; it is added only once billing opens, and it never runs on other sites.

Retention and your rights

Local data stays on your device until you clear it or uninstall SheetSpeed. Billing records, once billing opens, are kept as long as tax law requires. To access or delete your account data, email us. California residents and others may have additional rights under applicable law; we honor verified requests.

Children

SheetSpeed is not directed at children under 13.
