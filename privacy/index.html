SheetSpeed Privacy Policy

Updated and effective October 19, 2026 · Operator: Philip Dressler, California, USA · Contact: jarvis@agi-jarvis.com

SheetSpeed adds keyboard shortcuts and formula tools to Google documents. This policy covers the extension, this website and support communications. You retain ownership of your documents. We do not sell personal data, use document contents for advertising, or use them to train AI models.

Know which version you are reviewing. As of this review, the published Core release uses local document controls and needs no Google account connection. The submitted 0.4.0 update adds optional connected tools; 0.4.1 is a prepared follow-up. The additional data flows below apply only to versions that include those features. Check the installed version and permissions in Chrome. See the version and permission comparison.

1. Local document and keyboard access

The extension runs on matching Google Sheets and Slides document pages; the 0.4 update also supports Docs. It reads document identifiers, selection and native menu/control state to invoke commands. Formula inspection reads formula text exposed by the open Sheets page. These content scripts run on the matching pages, not solely when you click the extension button.

SheetSpeed matches keyboard events to shortcuts; it does not record ordinary typing as a keystroke log. Local diagnostics can retain the latest modifier event and control/menu metadata. The Docs command adapter operates native controls and does not send document text to a SheetSpeed service.

2. Optional Google-connected tools

In a version with connected tools, you authorize Google access before using them. Requests go directly from the browser to Google. Spreadsheet tools can read values, formulas, formatting and workbook metadata; dependent tracing can inspect multiple tabs in the selected workbook. Commands that edit a file write to Google. Interrupted modeling operations retain recovery information locally. When the extension next checks its status, it can resume restoration of inputs in previously affected spreadsheets, even if those spreadsheets are not currently open.

The spreadsheet tools request the Sheets scope. Slides refresh additionally requests Slides and Drive-file access. The extension manifest declares the supported permissions; Chrome's installation warning and Google's account-consent screen are separate. Google or your administrator can deny access.

Chrome manages the Google access token. The extension uses it for Google API requests and does not send it to a SheetSpeed-operated backend. Disconnect clears Chrome's cached authorization tokens; to revoke the underlying grant, remove SheetSpeed at Google account permissions. Revocation does not delete your Google documents.

SheetSpeed's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including Limited Use. Google user data is not used for advertising, sold, or used to train generalized AI models.

3. Refreshing a Sheets image in Slides

This optional feature re-reads the range linked to a SheetSpeed image, renders a PNG in the browser, and replaces the image in the current presentation. Refresh occurs when you invoke it, not continuously in the background. The source spreadsheet, tab and range are recorded in the image's link and alternative text and can be visible to people who can access the presentation.

To let Google Slides fetch the PNG, SheetSpeed uploads it to your Google Drive and creates an “anyone with the link can view” permission with discovery disabled. Anyone who obtains that URL while the permission remains active can view the image. Discovery being disabled does not make the link private. Organizations that prohibit this sharing can block the feature; use native shortcuts without enabling it.

The implementation attempts to remove the link permission and delete the temporary file after the update, including handled failures. Cleanup is not guaranteed if the browser closes, the worker stops, the network fails, or Google rejects a request. The next refresh attempts to find and remove leftover temporary files; there is no fixed maximum lifetime. Reported cleanup errors identify files to remove manually. Look for SheetSpeed refresh (temporary).png in Drive if an operation was interrupted. Do not use this flow for data your organization prohibits from link sharing.

4. Data stored on your device

  • Settings: shortcut bindings, enabled state and timeouts use Chrome local storage. Connected builds can optionally sync settings through Chrome sync storage. Published Core keeps its settings local.
  • Undo and recovery: connected edits can store original cell values, formulas, formatting, file identifiers and recovery journals locally. The implementation caps ordinary undo history by count and size and applies age pruning during history processing; uncertain or interrupted recovery records are retained until resolved. These are not server backups or a guaranteed timed deletion service. Clear undo history in Settings after resolving pending recovery.
  • Copy operations: Google/native copy commands can place data on the operating system clipboard. In connected builds, Paste Exact and format-copy buffers use Chrome session storage; session data is cleared when Chrome restarts or the extension reloads. A tab closing does not guarantee every buffer is erased. Replace or clear the system clipboard separately.
  • Protection: browser-profile and operating-system protections apply. SheetSpeed does not add its own encryption layer to local records. Removing the extension clears its local extension storage; it does not remove exports, your Google documents, support emails or files already copied elsewhere. Chrome sync data follows Google's sync controls.

6. Support, retention and requests

If you contact us, we use the information you provide to answer the request, investigate the issue and maintain necessary business or legal records. Support email is retained for those purposes; a fixed automatic deletion period is not currently implemented. Hosting providers apply their own retention rules. We do not promise that uninstalling the extension deletes records held by those providers.

For access, correction or deletion requests, contact jarvis@agi-jarvis.com. We may verify the requester's identity and retain information required by law or needed for unresolved disputes. Rights depend on applicable law. We cannot delete your Google documents or data stored only on your device from our support mailbox; use the controls described above.

The operator is in the United States and the listed providers may process website/support information in other countries. SheetSpeed offers no separate data-residency guarantee. Enterprise contract or data-processing requirements should be agreed before deployment; this policy is not a signed data processing agreement.

7. Children, updates and contact

SheetSpeed is not directed at children under 13. Changes will be posted here with a revised date; changes to extension access must also be reflected in the relevant Store disclosures and permission requests. Security reports and vendor questionnaires can be sent to jarvis@agi-jarvis.com. See the security page for reporting guidance.
