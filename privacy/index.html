SheetSpeed Privacy Policy

Product: SheetSpeed (Chrome listing title: SheetSpeed Core) · Updated: October 18, 2026

Official website: https://sheetspeed.agi-jarvis.com/ · Chrome Web Store: Store listing · Store ID ljlmgielacploapelnjhodicgbjipcaa.

Published privacy policy for the SheetSpeed Core Chrome extension. Contact jarvis@agi-jarvis.com.

Effective October 15, 2026. Operator: Philip Dressler, California, USA.

SheetSpeed is a Chrome extension that adds keyboard shortcuts and formula tools to Google documents. The free version runs entirely inside the open document and does not connect to your Google account. Some versions of SheetSpeed include optional features that work with your spreadsheet or presentation through Google's APIs; those features do nothing unless you choose to connect your Google account. We do not sell personal data, use it for advertising, or use it to train AI models.

The Chrome Web Store listing shows the permissions of the version you install. The sections below that start with “If” apply only when your installed version includes that feature and you use it.

Data SheetSpeed accesses

  • Document context. On the Google Sheets, Slides or Docs pages where your version of SheetSpeed runs, it reads the visible formula text, document and tab identifiers, the selected range, and native menu, toolbar and control state so it can run the command you choose. This happens locally on the page. SheetSpeed does not read, store or send the text of your Google Docs.
  • Keyboard events. SheetSpeed checks key presses against your configured shortcuts. It does not log ordinary typing or cell contents. Local diagnostics may keep the latest modifier event and element/menu metadata on your device.
  • Spreadsheet data (only if you use a feature that requires Google sign-in). If your version includes tools that connect to Google (for example trace dependents, goal seek, what-if tables or image export) and you connect your Google account, SheetSpeed calls the Google Sheets API for the spreadsheet you are working in to read the cells, formulas and formatting that tool needs, and, for tools that change the sheet, to write the result you confirm.
  • Slides images (only if you use a refresh-from-Sheets feature). If your version includes refreshing SheetSpeed-exported images in Google Slides and you use it, SheetSpeed reads that slide to find images it previously exported (identified by the source spreadsheet link stored in the image’s link and alt text), re-reads that source range through the Google Sheets API, renders a new PNG in your browser, and replaces the image in place. It only touches the slide and presentation you are editing.
  • Account and license (only if you purchase a paid plan). If paid plans are offered and you buy one, your email address and plan status are handled by ExtensionPay.

Google account connection (only if you use features that require Google sign-in)

  • The free version does not request the identity permission and never connects to your Google account.
  • If your version includes features that require Google sign-in, SheetSpeed uses Chrome's identity permission to ask Google for an access token. Google shows you a consent screen first, and nothing is connected unless you approve. Scopes are requested only when needed:
    • For spreadsheet tools: only https://www.googleapis.com/auth/spreadsheets, to read and write the spreadsheet you run the tool on.
    • Only the first time you refresh a SheetSpeed image in Google Slides: additionally https://www.googleapis.com/auth/presentations, to read the current slide and replace SheetSpeed images on it, and https://www.googleapis.com/auth/drive.file, which lets SheetSpeed create and manage only the temporary files it creates itself. SheetSpeed cannot see, list or open any other file in your Drive.
  • The token is managed by Chrome. It is used only from your browser, only to call the Google APIs listed under Permissions, and only for the spreadsheet or presentation open in your tab (plus, for Slides refresh, the source spreadsheet of each SheetSpeed image on that slide). SheetSpeed has no server that receives your token or your spreadsheet data.
  • Google may show an “unverified app” notice while Google's verification is pending.
  • You can disconnect from SheetSpeed's panel or Settings at any time, and revoke access at myaccount.google.com/permissions.
  • SheetSpeed's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Refreshing Sheets images in Slides (only if you use it)

  • Google Slides can only replace an image from a web address, so for each image being refreshed SheetSpeed uploads the new PNG to your own Google Drive as a temporary file (“SheetSpeed refresh (temporary).png”) and gives it a temporary “anyone with the link can view” share with discovery turned off, so it cannot be found by search.
  • The link is used only by Google Slides to fetch the image. Immediately afterwards, whether the update succeeded or failed, SheetSpeed removes the link share and deletes the temporary file. No SheetSpeed file stays in your Drive. If removal ever fails, SheetSpeed tells you so you can delete the file yourself. If an upload succeeded but its confirmation was lost, the next refresh finds that leftover temporary file (by its name or a SheetSpeed tag; drive.file only shows files SheetSpeed created) and deletes it.
  • The image contains only the cells of the original exported range. The refreshed image keeps its size and position, and its link and alt text record the source spreadsheet, tab and range so it can be refreshed again. Nothing else is stored, and nothing is sent to a SheetSpeed server.

Storage

  • Shortcut settings, enabled state and timeouts are stored in Chrome local storage on your device. If you turn on settings sync, they are also stored in Chrome sync storage under your Chrome profile.
  • If you use a tool that changes your sheet through the Google Sheets API, SheetSpeed keeps a local undo record (the original values and formatting of the affected cells) on your device so you can reverse the change. Undo records are bounded in size and you can clear them in Settings.
  • If you purchase a paid plan, the cached license status is stored locally and ExtensionPay keeps a login token in Chrome storage.

Transmission and processors

  • Google (only if you use features that require Google sign-in): Sheets API requests go directly from your browser to sheets.googleapis.com. Slides refresh requests go directly to slides.googleapis.com and the Google Drive API at www.googleapis.com/drive/v3 and www.googleapis.com/upload/drive/v3.
  • ExtensionPay (privacy, only if you purchase a paid plan): license and login checks. Your email and plan status are sent, but never your spreadsheet data.
  • Stripe (privacy, only if you purchase a paid plan): payment processing, receipts and the subscription portal. Card numbers never reach SheetSpeed or ExtensionPay.
  • Developer servers: none. AI providers: none. The Chrome Web Store version does not include an AI helper.

Permissions

Every version uses storage and activeTab. The others are present only in versions that include the matching feature; the Chrome Web Store shows the exact list for the version you install.

  • storage: settings, undo records and license cache, as described above.
  • activeTab: interact with the Google document you are using when you invoke SheetSpeed.
  • Content scripts on Google Sheets and Slides document pages (and Google Docs pages in versions that support Docs) for the shortcuts and panel. On Docs, processing is local only, with no API calls.
  • If present, identity: get a Google access token, with your consent, for features that require Google sign-in.
  • If present, host permission https://sheets.googleapis.com/*: call the Google Sheets API for those features.
  • If present, host permissions https://slides.googleapis.com/*, https://www.googleapis.com/drive/v3/* and https://www.googleapis.com/upload/drive/v3/*: Slides refresh only (read the slide, replace the image, and upload, share, unshare, find and delete the temporary image file).
  • If present, a content script on extensionpay.com: license sign-in and payment confirmation for paid plans. It never runs on other sites.

Retention and your rights

Local data stays on your device until you clear it or uninstall SheetSpeed. If you purchase a paid plan, billing records are kept as long as tax law requires. To access or delete your account data, email us. California residents and others may have additional rights under applicable law; we honor verified requests.

Children

SheetSpeed is not directed at children under 13.

Changes

We will post changes on this page and update the effective date. Material changes will also be reflected in Chrome Web Store disclosures.
