Key features

Speed and accuracy tools for Sheets — keyboard-first, panel-backed.

Trace precedents

Open a panel on the active formula. List every direct reference, jump with ↑↓, drill with Enter, return with F5. Escape closes. Core reads the visible formula; Full can enrich with values when Google is connected.

Trace dependents

Scan for cells that reference the selection. Bounded, cancelable searches keep partial matches and say when coverage stopped short — never a silent empty “none.”

Goal seek

Pick a formula cell, a target, and one input. Preview the solved value, then apply only when you choose.

What-if analysis

One- or two-input scenario tables from a selected model range. Review results before writeback.

Format cycles

Number, percent, date, currency, and more — cycle custom formats on the selection. Same idea for font and fill colors.

Auto-color

Flag hardcodes and cross-tab links on a selection or whole sheet. API path; undo via SheetSpeed history where supported.

Export selection as image

Render the selected range to PNG for Slides or Docs. Clipboard write when the browser allows; manual copy/download otherwise.

Excel-shaped Sheets shortcuts

Insert/delete, paste special, borders, freeze, merge, filters, alignment, decimals, zoom, and more — routed through Google’s own UI where possible.

PowerPoint-shaped Slides shortcuts

Ordering, distribute, align objects/text, group/ungroup, font size — on selected shapes.

Customizable shortcuts

Change bindings in Settings. Export/share Core settings; Full keeps richer cycles and sync options.
