Key features

Excel, Word and PowerPoint Alt shortcuts with on-screen key tips across Google Sheets, Docs and Slides: 500+ commands, 140+ Docs shortcuts.

Core is free forever. Pro tools are free during early access; prices ($7.99/mo, $69/yr, $149 lifetime) start only when billing opens, with notice first. Pro includes trace dependents, goal seek, what-if tables, freeze panes, auto-color, export as image, font/fill color cycles, number format cycles, format painter, clear filters, clear all, Paste Exact, and refresh linked Slides images (Ctrl+Alt+Shift+R). Future Pro tools are included at no extra cost. See Pricing.

Trace precedents (Free)

Open a panel on the active formula — the Sheets equivalent of Excel’s Trace Precedents. List every direct reference, jump with ↑↓, drill with Enter, return with F5. Escape closes. Free in Core.

Trace dependents (Pro)

Scan for cells that reference the selection. Bounded, cancelable searches keep partial matches and say when coverage stopped short.

Goal seek (Pro)

Pick a formula cell, a target, and one input. Preview the solved value, then apply only when you choose. Alt, A, W, G.

What-if analysis (Pro)

One- or two-input scenario tables from a selected model range. Review results before writeback. Alt, A, W, T.

Format cycles (Pro)

Number, percent, date, currency, and more — cycle custom formats on the selection. Same idea for font and fill colors.

Auto-color (Pro)

Flag hardcodes and cross-tab links on a selection or whole sheet.

Paste Exact (Pro)

Copy with Ctrl+Alt+Shift+C, paste with Ctrl+Alt+Shift+V. Formulas land exactly as copied, so relative references don't shift when you paste.

Refresh linked Slides images (Pro)

Press Ctrl+Alt+Shift+R to refresh Slides images exported from a Sheets range, so the deck matches the latest numbers. In Google Slides this is Refresh from Sheets.

Export selection as image (Pro)

Render the selected range to PNG for Slides or Docs. Clipboard write when the browser allows; manual copy/download otherwise.
