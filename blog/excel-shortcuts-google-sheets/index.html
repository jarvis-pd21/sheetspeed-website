Option A — SheetSpeed

SheetSpeed is a Chrome extension that brings Excel, Word and PowerPoint Alt shortcuts with on-screen key tips to Google Sheets, Docs and Slides: 500+ commands, 140+ Docs shortcuts, plus free trace precedents.

Core is free on the Store and does not require a Google account connection: Excel-style shortcuts, Alt sequences, trace precedents, a command palette, and Slides chords. Pro tools are free during early access; prices ($7.99/mo, $69/yr, $149 lifetime) start only when billing opens, with notice first. Pro includes trace dependents, goal seek, what-if tables, freeze panes, auto-color, export as image, font/fill color cycles, number format cycles, format painter, clear filters, clear all, Paste Exact, and refresh linked Slides images (Ctrl+Alt+Shift+R). Future Pro tools are included at no extra cost.

Option B — SheetWhiz

SheetWhiz is a well-known Chrome extension for Excel-like shortcuts in Google Sheets. SheetSpeed is an independently authored alternative; compare current Store listings and features rather than assuming parity.

Other Store options (verify live)
