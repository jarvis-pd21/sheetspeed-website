How to Get Excel Shortcuts in Google Sheets (2026 Guide for Excel Switchers)

You switched to Google Sheets, and your hands still type Alt, E, S, V. Here's how to get as much of your Excel muscle memory back as possible, starting with the free option built into Sheets.

If you spent years in Excel, the first week in Google Sheets is frustrating. Not because Sheets is bad, but because your fingers keep reaching for shortcuts that don't exist. You press Alt, H, B to add a border and nothing happens. You press Ctrl+[ to jump to a formula's inputs and nothing happens. You reach for the mouse, and that's where the time goes.

The good news: you can recover most of it. This guide covers the three layers that help, in the order you should try them.

Layer 1: Turn on Google's "compatible spreadsheet shortcuts" (free, 30 seconds)

Google Sheets ships with an Excel compatibility mode that most switchers never find.

  1. Open any spreadsheet at sheets.google.com.
  2. Click Help → Keyboard shortcuts (or press Ctrl+/ on Windows, ⌘+/ on Mac).
  3. At the bottom of the window, turn on Enable compatible spreadsheet shortcuts.

This maps many common Excel Ctrl shortcuts to their Sheets equivalents. It costs nothing and requires no install, so do it first, even if you plan to add an extension later.

What it does not give you:

  • Excel's sequential Alt "ribbon" paths. In Excel, you press Alt, release it, then tap H, then B, then O. Sheets has no ribbon, so these sequences don't work the same way. Some Alt-based shortcuts appear in compatibility mode, but they generally expect you to hold keys together rather than tap them in sequence.
  • Formula auditing. Sheets has no built-in Trace Precedents or Trace Dependents. You can click into a formula and see colored range borders, but you can't list every input and jump between them from the keyboard.
  • Excel's What-If Analysis tools. Goal Seek and data tables aren't built into Sheets.

For casual users, layer 1 is enough. For analysts, modelers and anyone in finance, it usually isn't.

Layer 3: Add a Chrome extension for the Excel-only habits

This is where Alt sequences, trace precedents and modeling tools come from. Several Chrome extensions fill this gap, and they take different approaches. Chrome extensions run in your browser and change how the Sheets page responds to your keyboard. Google Workspace add-ons run in a sidebar inside the file. For keyboard shortcuts specifically, Chrome extensions are the type that can catch your keystrokes.

A 10-minute setup for Excel switchers

  1. Turn on Enable compatible spreadsheet shortcuts (Help → Keyboard shortcuts).
  2. Install one extension. Pick from the menu above based on what you miss most.
  3. Open a real model you know well, not a blank sheet. Muscle memory comes back fastest on familiar work.
  4. Try your top five shortcuts: for most analysts that's paste values, insert/delete rows, borders and trace precedents.
  5. Remap any shortcut that conflicts with your OS or another extension.
  6. Keep Alt+/ (search the menus) as your fallback for everything else.

FAQ

Can Google Sheets use Excel shortcuts without an extension?
Partly. Turn on "Enable compatible spreadsheet shortcuts" under Help → Keyboard shortcuts. That covers many Ctrl shortcuts but not sequential Alt paths or trace precedents.

Is there a free way to trace precedents in Google Sheets?
Yes. SheetSpeed's free Core includes trace precedents on the active formula (Ctrl+Shift+[).

Should I get an add-on or a Chrome extension?
For keyboard shortcuts, a Chrome extension. Add-ons run in a sidebar and can't catch keystrokes the same way.

Do these extensions work in Edge or Brave?
Chromium browsers can generally install Chrome Web Store extensions, but each vendor tests Chrome first. Check the listing.
