"Enable Compatible Spreadsheet Shortcuts" in Google Sheets: What It Does and Doesn't Do

The free, built-in first step for every Excel switcher, and its limits.

How to turn it on

  1. Open a spreadsheet in Google Sheets.
  2. Click Help → Keyboard shortcuts (Ctrl+/ or ⌘+/).
  3. Turn on Enable compatible spreadsheet shortcuts at the bottom.

That's it. The setting follows your Google account.

What it covers

Many Excel-style Ctrl shortcuts start working the way you expect. You can search the Keyboard shortcuts dialog for an action (for example "border") to see which key it now uses.

What it doesn't cover

  • Sequential Alt paths. Excel lets you press and release Alt, then tap H, B, O. In Sheets, Alt-based shortcuts generally need keys held together, which breaks muscle memory.
  • Trace precedents and dependents. Not built into Sheets.
  • Goal Seek and data tables. Not built into Sheets.
  • Some shortcuts the browser owns. Chrome reserves certain combinations, such as Ctrl+W and Ctrl+T.

Should you still turn it on if you use an extension?

Usually yes. Extensions like SheetSpeed fill the gaps (Alt sequences, trace precedents) while the built-in setting handles the rest. If a shortcut behaves oddly, check whether both are trying to handle it, and remap one in the extension's settings.
