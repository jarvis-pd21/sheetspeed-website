Google Sheets Shortcuts List: Windows, Mac and Excel Equivalents

The built-in Google Sheets keyboard shortcuts, grouped by task, with the Excel shortcut you already know next to each one. Plus the Excel habits Sheets doesn't support, and how to get them back.

How to use this list

This is a reference of Google Sheets' built-in keyboard shortcuts, grouped by task, with the Mac version and the Excel shortcut you already know in the last column, so you can see at a glance what carries over and what doesn't.

  • The Windows/ChromeOS and Mac columns come from Google's own Keyboard shortcuts for Google Sheets help page (checked 2026-10-17). Some shortcuts vary by language and keyboard layout.
  • The Excel column shows default shortcuts in Excel for Windows. "—" means there's no direct equivalent.
  • Ctrl+C means hold both keys. Alt, E, S, V means press and release each key in turn.
  • In Sheets, press Ctrl+/ (⌘+/ on Mac) to search every shortcut, and Alt+/ to search the menus.

We make SheetSpeed, a Chrome extension that adds Excel-style shortcuts to Google Sheets. Everything in the first six tables works without it.

Mac notes

  • Use ⌘ where Windows uses Ctrl for most shortcuts, and Option where Windows uses Alt.
  • Number formats (Ctrl+Shift+1–6), select column (Ctrl+Space) and show formulas (Ctrl+~) keep Ctrl on Mac.
  • Menus open with Ctrl+Option+letter (for example Ctrl+Option+I for Insert).
  • On laptop keyboards, Home/End and the F-keys need Fn.
  • Extensions like SheetSpeed map Excel's Alt sequences to Option. More: Excel Alt shortcuts on a Mac in Google Sheets.

FAQ

Where can I see every keyboard shortcut in Google Sheets?

Inside any spreadsheet, press Ctrl+/ on Windows or ChromeOS (⌘+/ on Mac) to open the Keyboard shortcuts dialog, which is searchable. Google also publishes the full list on its "Keyboard shortcuts for Google Sheets" help page. This page reproduces the main ones for Windows and Mac next to their Excel equivalents.

What is the Google Sheets shortcut for paste values?

Ctrl+Shift+V on Windows and ChromeOS, ⌘+Shift+V on Mac. Excel's Alt, E, S, V sequence doesn't work natively in Sheets; a Chrome extension such as SheetSpeed (free Core) adds it.

What is the shortcut to insert a row in Google Sheets?

Select one or more rows and press Ctrl+Alt+= (⌘+Option+= on Mac) to insert rows above. Ctrl+Alt+- deletes them. Excel's Ctrl+Shift+= and Ctrl+- work after you turn on "Enable compatible spreadsheet shortcuts" or install an extension like SheetSpeed.

Do Excel shortcuts work in Google Sheets?

Many basics are identical (Ctrl+C/V/Z/Y, Ctrl+D, Ctrl+R, Ctrl+F, Ctrl+H, Ctrl+Space, Shift+Space, F4). Others differ: insert/delete rows, hide rows and columns, sheet navigation and most of Excel's press-and-release Alt ribbon sequences. Turn on Help → Keyboard shortcuts → "Enable compatible spreadsheet shortcuts" for more Excel-style keys, and use an extension for Alt sequences and trace precedents.

Is there a trace precedents shortcut in Google Sheets?

Not natively; Google Sheets has no formula auditing tools like Excel's Trace Precedents. SheetSpeed adds a precedents panel on Ctrl+Shift+[ in its free Core.

Are Google Sheets shortcuts different on a Mac?

Yes. Most Ctrl shortcuts use ⌘ on a Mac, Alt becomes Option, and keys like Home, End and F4 need Fn on laptop keyboards. Number-format shortcuts (Ctrl+Shift+1 to 6) keep Ctrl on Mac.
