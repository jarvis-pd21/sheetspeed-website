Goal Seek in Google Sheets: Your Options in 2026

Solving for the input that hits a target: how to do it in Sheets.

Excel's Data → What-If Analysis → Goal Seek (Alt, A, W, G) changes one input until a formula hits a target value. Google Sheets has no built-in equivalent, but you have options.

Option 1: A Workspace Marketplace add-on

Search the Google Workspace Marketplace (Extensions → Add-ons → Get add-ons) for "Goal Seek". Add-ons run in a sidebar: you pick the target cell, target value and changing cell, then run it.

Option 2: Chrome extensions with Excel keys

Several Excel-shortcut extensions add goal seek on Alt, A, W, G:

  • SheetWhiz, XLKeys and ShortieCuts list goal seek on their sites.
  • SheetSpeed Pro (launching soon) adds goal seek with a preview of the solved value before anything is written, plus one- and two-variable what-if tables on Alt, A, W, T. Planned pricing is $7.99/mo, $69/yr or $149 lifetime, with a 14-day trial.

Option 3: Do it by hand

For simple linear models, rearrange the formula algebraically and solve for the input directly. For anything else, set up a small table of candidate inputs and read off where the output crosses your target.

Which to pick

If you only need goal seek occasionally, an add-on is fine. If you live in models and want Excel's keystroke, use an extension.
