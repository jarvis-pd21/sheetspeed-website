A Command Palette for Google Sheets (and When to Use Alt+/ Instead)

Two ways to run a command by name without leaving the keyboard.

Nobody remembers every shortcut. A command palette lets you type what you want and press Enter.

Built in: Alt+/ (search the menus)

Google Sheets has a menu search on Alt+/ (Option+/ on Mac). Type "freeze", "paste special" or "conditional formatting" and pick the result. It covers every native menu item and it's free.

SheetSpeed's palette: Ctrl+Shift+Space

SheetSpeed adds a palette on Ctrl+Shift+Space (Control+Shift+Space on Mac). It searches SheetSpeed's own commands in Sheets and Slides, such as trace precedents, Excel-style paste special and formatting routes.

Which to use

  • Native menu item you can't find: Alt+/.
  • An Excel-style SheetSpeed command: Ctrl+Shift+Space.

Both are keyboard-only, so your hands stay put.
