Excel Alt Shortcuts on a Mac in Google Sheets (Use Option)

Windows Excel habits on a MacBook, in a browser. Here's the translation table.

Many analysts learned Excel on Windows and now use a Mac with Google Sheets. SheetSpeed’s named shortcuts and Google’s built-in shortcuts use different rules. For the SheetSpeed defaults shown here:

Windows ExcelMac + Google Sheets with SheetSpeed
AltOption (⌥)
Ctrl in a SheetSpeed shortcutControl (⌃), unless changed in Settings

Examples

ActionWindowsMac
Paste valuesAlt, E, S, VOption, E, S, V
BordersAlt, H, B + letterOption, H, B + letter
Trace precedentsCtrl+Shift+[Control+Shift+[
Insert rowsCtrl+Shift+=Control+Shift+=

For Google’s built-in copy, paste and other shortcuts, use its platform-specific shortcut list. For example, native copy uses Command+C on a Mac. That does not change SheetSpeed’s named Control chords.

Gotchas

  • Option types special characters on a Mac (Option+E is an accent key). An extension has to catch the sequence before the character is typed. If a stray character appears in a cell, press Esc and check that the extension is enabled on that tab.
  • The command palette (Control+Shift+Space) may clash with input-source switching on some Macs. Remap it in SheetSpeed Settings.
  • The F5 key needs Fn on most Mac keyboards unless you've changed the function-key setting.
