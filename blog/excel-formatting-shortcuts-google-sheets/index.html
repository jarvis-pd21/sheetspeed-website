Borders, Freeze Panes and Filters: Excel Formatting Shortcuts in Google Sheets

The everyday Excel formatting keys, and what each one does in Sheets.

The shortcuts

ActionExcel keysIn Google Sheets with SheetSpeed (free Core)
BordersAlt, H, B + letterOpens the native borders palette
Freeze panesAlt, W, F, FFreezes rows above and columns left of the selection (Pro)
Toggle filterCtrl+Shift+LCreates or removes a filter
Insert rowsCtrl+Shift+=Native Insert → Rows
Delete rowsCtrl+Shift+-Native Edit → Delete → Rows

Tools marked Pro are free during early access. Pro unlocks free in v0.3.2, the next store update.

How they work

SheetSpeed doesn't edit your spreadsheet directly for these. It triggers Sheets' own commands, so the result is the same as using the menu. Undo (Ctrl+Z) works normally.

Without an extension

  • Borders: the toolbar borders button, or Alt+/ then "border".
  • Freeze: View → Freeze.
  • Filter: Data → Create a filter.
  • Insert rows: right-click → Insert row above.

Remapping

Every SheetSpeed binding can be changed in Settings, which is handy if your team standardizes on different keys.
