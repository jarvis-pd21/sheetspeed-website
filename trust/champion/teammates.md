# For teammates — day one and a short FAQ

**About two minutes.** This is what changes if your team is in a SheetSpeed pilot. It does not change how Google files are stored.

## Day one

1. Your admin may allow the extension, or you may install **SheetSpeed** from the Chrome Web Store (ID `ljlmgielacploapelnjhodicgbjipcaa`). Use only the Store listing your admin named.
2. Open an existing Google Sheet, Doc or Slide — there is no new file type.
3. Try a familiar Excel-style shortcut, or hold Alt (Option on a Mac) to see key tips. Core shortcuts do not ask you to connect Google.
4. Some optional tools (the Pro set) will ask for Google permission if you use them. You can decline and keep using Core.
5. If something gets in the way, tell [champion] rather than struggling through the pilot in silence.

Product walkthroughs live on the SheetSpeed site: https://sheetspeed.agi-jarvis.com/

## Will this make my job harder?

**Usually no, and you can turn it off.** It adds keyboard shortcuts to the Google files you already have. It is not a new editor and not a new login for Core.

**Will it see my email or my other tabs?** Content scripts run only on Google Sheets, Docs and Slides document pages, not on your other sites. It is not a keylogger.

**Does my spreadsheet go to SheetSpeed?** No. Content stays in Google. Optional Pro tools talk to Google from your browser after you consent.

**What if I do not want it?** If it was not force-installed, remove it from `chrome://extensions`. If it was force-installed, ask your admin. You can also revoke Google access at https://myaccount.google.com/permissions.

**Is this permanent?** No. The team has a go/no-go date. This is a trial against written criteria.
