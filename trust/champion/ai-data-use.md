# AI and data-use statement

**This statement covers version 0.4.6. The Chrome Web Store rollout is pending store review.**

SheetSpeed’s **0.4.6 package does not send your spreadsheet, Doc or Slide content to an AI model, and it does not include a working AI feature.** There is no claim that customer content is used to train a model, because that content is not sent to Dressler Labs or to an AI vendor.

Version 0.4.6 does not include a local companion app. The package has no local-companion permission and no companion host, and Settings does not mention a local model. Review the Store package when you assess production risk.

**Core** shortcuts and key tips run locally in the browser and do not call a Google API.

**Pro** tools, after the user consents, call Google APIs from the browser. That is Google’s API, not an AI service.

**Website:** Cloudflare Web Analytics may collect ordinary site-visit metrics. It does not receive spreadsheet content.

If an AI feature ships later, this statement should be rewritten before that release, not afterwards.

Last updated 19 November 2026.
