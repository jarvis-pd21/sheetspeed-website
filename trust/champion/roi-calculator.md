# ROI worksheet (expected and downside)

Use with the business case. **Hard savings first. Hours saved are a soft estimate, not hard ROI.**

During early access, subscription cost is **$0**. For a post-billing scenario, use the published **$69/user/year** unless you have a written quote.

| Line | Formula | Expected | Downside |
| --- | --- | --- | --- |
| A. Seats | Buyer input | | |
| B. Price per seat per year | List $69, or $0 in early access | | |
| C. Annual subscription | A × B | | |
| D. Hard savings (cancelled tools, etc.) | Buyer input; $0 if none | | |
| E. **Net hard $** | D − C | | |
| F. N, H, S, W | See business case | | |
| G. Hours/year (estimate) | N × H × S × W | | |
| H. Soft $ view of time | G × your $/hour, if required | | |
| I. Do **not** add H into E | Hours are not hard savings | — | — |

A worked **illustration only** (not a promise): 10 seats, early access so C = $0, no cancelled tools so D = $0, net hard $ = $0. Soft estimate at S = 5%, H = 15, W = 48: 360 hours/year. Downside at S = 0%: 0 hours. Finance should look at E first.
