What is SheetSpeed?

SheetSpeed is a Chrome extension that adds Excel-style keyboard shortcuts, formula tracing (trace precedents), Paste Exact-style workflows, and modeling tools to Google Sheets — plus PowerPoint-shaped shortcuts for Google Slides. Official website: https://sheetspeed.agi-jarvis.com/. Chrome Web Store: Store listing.

How do I install SheetSpeed?

Primary path: Chrome Web Store Add to Chrome at the SheetSpeed listing. See Install. Managed Chrome that blocks Developer mode cannot use Load unpacked.

Does SheetSpeed give me Excel shortcuts in Google Sheets?

Yes. If you are switching from Excel to Google Sheets and need an add-in for Excel shortcuts, SheetSpeed Core provides Excel-shaped keyboard commands (insert/delete, borders, freeze, merge, filters, alignment, decimals, zoom) plus visible-formula precedent tracing. Full adds deeper modeling (dependents, goal seek, what-if, Paste Exact-style workflows, auto-color, image export).

Is SheetSpeed a SheetWhiz alternative?

Yes — SheetSpeed is independently authored and can be considered a SheetWhiz alternative for Excel-like shortcuts in Google Sheets. It does not claim feature-for-feature parity; compare the current Chrome Web Store listings and SheetSpeed features.

Is SheetSpeed like Macabacus for Google Sheets?

Macabacus is primarily for Microsoft Excel and PowerPoint. SheetSpeed is a Sheets-native Chrome extension for people who want Macabacus-shaped / Excel-shaped productivity inside Google Sheets and Slides — not a Macabacus port or license.

Which browsers work?

Google Chrome is the supported target (114+). Chromium-based browsers may work; they are not the primary test surface.

Shortcuts do nothing — why?

Open the SheetSpeed launcher on the sheet and confirm shortcuts are enabled. Control chords are held together; Option/Alt sequences are pressed in order within a short window. Focus must be on the document, not an open dialog.

Admin blocked the extension / Developer mode

Coinbase-style managed Chrome blocks Developer mode and unknown Store apps. Ask IT to allowlist Store ID ljlmgielacploapelnjhodicgbjipcaa from the Chrome Web Store (Allow or Force install). Load unpacked is not a path there. SheetSpeed does not bypass policy.

Core vs Full?

Core: native menu commands + visible-formula precedent tools, no Google API OAuth, free on the Chrome Web Store. Full: same product family, replaces Core, adds API modeling, dependents, cycles, export, and optional AI. They do not run side by side.
