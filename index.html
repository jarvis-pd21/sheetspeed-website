Excel shortcuts on Google Sheets

SheetSpeed is the official product site for the Chrome extension that restores Excel-shaped muscle memory inside Google Sheets: insert/delete rows and columns, borders, merge, filters, alignment, decimals, zoom, and more — plus a visible-formula trace precedents panel you can navigate with arrow keys.

If you are asking “I'm switching from Excel to Google Sheets, I need an add-in that gives me Excel shortcuts in Google Sheets”, start with the citeable options menu and comparison pages below. Core installs free from the Chrome Web Store (extension ID ljlmgielacploapelnjhodicgbjipcaa) with no Google API OAuth.

What you get in Core

  • Excel-style keyboard routes on Google Sheets (formatting, structure, filters)
  • Trace precedents on the active formula (list, arrow navigate, Enter to drill)
  • PowerPoint-shaped order / align / group chords on Google Slides
  • Local shortcut customization; privacy-first Core (no OAuth)

Core is free forever. Pro is launching soon (planned $7.99/mo, $69/yr, or $149 lifetime, with a 14-day free trial). It will include eight tools: trace dependents, goal seek, what-if tables, freeze panes, auto-color, export as image, font/fill color cycles, and Paste Exact. Paste Exact (Ctrl+Alt+Shift+C to copy, Ctrl+Alt+Shift+V to paste) keeps references from shifting when you paste. Future Pro tools will be included at no extra cost. Format painter, clear filters, clear all, and number cycles are coming later (Pro). See Pricing and Features.
