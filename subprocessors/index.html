SheetSpeed subprocessors

Product: SheetSpeed · Official website: https://sheetspeed.agi-jarvis.com/ · Related: Data Processing Agreement · Privacy Policy

Updated: 10 November 2026. Operator: Philip Dressler, doing business as Dressler Labs, California, USA.

Dressler Labs uses the vendors below in connection with SheetSpeed. Spreadsheet, document and presentation content is not sent to Dressler Labs or to a SheetSpeed server. When a user runs a Pro tool after connecting Google, the browser calls Google’s APIs under that user’s Google account. Those API calls are listed here for completeness; Dressler Labs does not receive that content and is not the processor of it. See the DPA and Privacy Policy.

We will update this page before a new subprocessor starts processing Customer Personal Data. Customers may object as described in the DPA.

Not listed, and why

  • No SheetSpeed application server, and no AI provider in the Chrome Web Store package.
  • No separate email or form provider. The site uses a mailto: link to jarvis@agi-jarvis.com; the mailbox is Google Workspace, listed above. There is no hosted contact form.
  • No first-party analytics script in the website source. The only analytics found on the live site is the Cloudflare Web Analytics beacon injected at the edge.
  • Chrome sync storage is the user’s own Chrome profile, if the user enables settings sync. It is not a Dressler Labs subprocessor.
  • SheetSpeed for Excel on Mac is a separate local app. The Security page states it has no network entitlement. It is not covered as processing under this list.
