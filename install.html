Personal Chrome with Developer mode (local Core / Full)

Only when your browser allows Developer mode. Not available on Coinbase-managed Chrome.

  1. Use the repo extension folder (Full) or npm run package:core and extract so manifest.json is at the folder root.
  2. Open chrome://extensions → enable Developer mode → Load unpacked → select that folder.
  3. Refresh a Google Sheet, Doc or Slide. Confirm the ◈ SheetSpeed launcher.
