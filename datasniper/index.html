DataSniper for Excel

Upload documents, snip fields on the first one, and export one row per file.

Download manifest.xml · Open the browser harness

DataSniper is a task pane add-in for Microsoft 365 Excel on Mac, Windows, and the web. It is not in AppSource and it is not deployed by an administrator from this page. You sideload the manifest yourself. The pages load from this site over HTTPS. The documents you upload stay in that Excel session’s browser storage on your machine.

What it does

  • Upload many PDFs at once. PNG, JPEG, and WebP images can be uploaded and viewed too.
  • The files open inside the task pane. Drag a rectangle on document 1 and name it. That snip is a column.
  • Drag the snips in the list to set the column order.
  • Export writes an Excel table named DataSniperExport at cell A1 of the active sheet: a header row from the snip names, a Source document column, and one row per file.
  • The boxes are page-relative. The same rectangle is read on every file, using the PDF text layer inside the box. A narrow box clips text that extends past it.
  • Click an exported cell while the task pane is open. Excel opens a preview of that file with the snip highlighted. Drag or resize the box and the cell updates.

Limits, stated plainly

  • A snip is a rectangle on a page, not a detected label. Every file has to share the same layout. A capital call with the investor name in a different place will not line up.
  • Export replaces a previous DataSniperExport table and writes from A1. It will overwrite whatever is already in that range.
  • Click-to-preview runs only while the DataSniper task pane is open. Closing the pane removes the selection listener until you open it again.
  • Files are stored in IndexedDB for sheetspeed.agi-jarvis.com inside the Excel webview (desktop) or the browser (Excel on the web). Clearing site data removes the files. The cell text remains; the preview cannot reopen a deleted file.
  • Desktop Excel and Excel on the web do not share that storage. A file uploaded in one does not appear in the other.
  • Scanned pages and images have no text layer. DataSniper then runs Tesseract.js in the browser. The first OCR run downloads the library and English traineddata from a public CDN. The cropped image is processed locally and is not uploaded. If that download is blocked, the cell is left blank and the status line says why.
  • The add-in needs network access to this site and to appsforoffice.microsoft.com to load. That traffic is the add-in itself, not your documents.
  • The browser harness is a fake workbook used for automated tests. It does not write an .xlsx file.

Excel on Mac

These steps match Microsoft’s sideload path for Microsoft 365 Excel on Mac: copy the manifest into the wef folder, then restart Excel. Quit Excel completely (Excel menu, Quit) before copying the file.

  1. Download manifest.xml.
  2. In Finder, choose Go > Go to Folder and open ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef.
  3. If that folder does not exist, create it. The parent Documents folder is there after Excel has been opened at least once.
  4. Copy manifest.xml into wef. The file name can stay manifest.xml.
  5. Open Excel. On the Home tab, use the DataSniper button. If the group is missing, look under Insert > Add-ins > My Add-ins.

Recent Microsoft 365 builds of Excel on Mac also show Upload My Add-in under Insert > Add-ins > My Add-ins. If that command is present, you can select the manifest from there instead of using wef. If it is not present, use the folder above. Microsoft documents the folder method at Sideload an Office add-in on Mac.

Excel on Windows

Two sideload methods work. Use whichever your Excel shows.

Upload My Add-in

  1. Download manifest.xml.
  2. In Excel, choose Insert > Add-ins > My Add-ins.
  3. Choose Upload My Add-in and select the manifest.

An organization can hide Upload My Add-in. If you do not see it, use a shared-folder catalog.

Shared-folder catalog

  1. Create a folder, for example C:\DataSniper, and put manifest.xml in it.
  2. Share the folder with yourself. Excel wants a UNC path, not a drive letter. A share named DataSniper is typically \\localhost\DataSniper.
  3. In Excel, choose File > Options > Trust Center > Trust Center Settings > Trusted Add-in Catalogs.
  4. Enter the UNC path as the catalog URL, check Show in Menu, and choose OK.
  5. Restart Excel. Choose Insert > My Add-ins > Shared Folder, then DataSniper.

Microsoft’s steps are at Create a network shared folder catalog.

Excel on the web

  1. Open a workbook at Excel on the web.
  2. Choose Insert > Add-ins > More Add-ins, then My Add-ins.
  3. Choose Upload My Add-in and select manifest.xml.
  4. The DataSniper task pane opens. The Home tab also has a DataSniper button.

Upload My Add-in on the web is for your own account. It is not an organization-wide deployment. If the command is missing, an admin has turned sideloading off and this page cannot override that. The manifest’s pages must stay reachable at https://sheetspeed.agi-jarvis.com/datasniper/, which is where this file is hosted.

Privacy

Uploaded documents are not sent to a DataSniper server. There is no account and no backend. PDF.js runs locally from files hosted with this add-in (Mozilla, Apache-2.0). Office.js is loaded from Microsoft when the page is opened inside Excel. OCR, only when a page has no text layer, loads Tesseract.js and English traineddata from jsDelivr. The page you are reading is hosted on the SheetSpeed site and is not linked from the SheetSpeed homepage.
