SheetSpeed for enterprise review

Technical review updated October 19, 2026 · Publisher contact: jarvis@agi-jarvis.com

Excel-style shortcuts in Google Sheets, with a small installation footprint. Start with the version and features your team intends to approve. This page gives IT, security and procurement a single place to review how SheetSpeed works.

Where data goes

  1. Native commands: your keyboard → extension running in the document page → Google's existing controls.
  2. Optional connected commands: browser → Google Sheets/Slides/Drive APIs → your Google files. Account scopes are broader than the particular file targeted by SheetSpeed's code.
  3. Local records: settings and, in connected builds, undo/recovery and copy buffers → Chrome storage on the user's device.
  4. Website and support: public website requests → GitHub Pages/Cloudflare/Google Fonts; support emails → our Google Workspace mailbox. These are separate from extension workbook processing.

The privacy policy provides the exact scopes, providers, retention limits and revocation instructions.

Managed deployment

  1. Review the Store package and its requested permissions for the version your organization will install.
  2. Allow or deploy extension ID ljlmgielacploapelnjhodicgbjipcaa through your approved Chrome management process. Developer mode or an unpacked extension is not required for the Store release.
  3. For connected features, review the Google OAuth application separately in your Workspace controls. Do not disable organization access or sharing policies to make a feature work.
  4. Test on a non-confidential workbook using your managed Chrome profile, keyboard layout and standard policies. Check formatting, native Undo, formula inspection and expected shortcuts.
  5. If approving the update, separately test consent denial, account revocation, local-history clearing and interrupted image cleanup. Skip linked-image refresh where anyone-with-link sharing is not permitted.
  6. Review Chrome's update controls with your administrator. A Store extension can receive later versions; an approved installation is not a permanent version freeze.

Allowlisting the extension alone does not approve Google OAuth scopes, external sharing, or a future AI integration. SheetSpeed does not bypass these controls.
